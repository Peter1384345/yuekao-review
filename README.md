# 高二上 · 第一次月考 六科复习站

一个纯静态、可交互的分科复习网站。**每科一个独立页面**，内置考点清单、二级结论、作文素材、单词表、语法、物理结论、化学方法与生物读图法，并配有 **3D 翻转闪卡**、即时自测与掌握度追踪。

线上地址：https://peter1384345.github.io/yuekao-review/

## 交互功能

- **3D 翻转闪卡**：点击卡片翻面，支持随机抽卡、打乱牌序、按标签筛选、「只看未掌握」、键盘快捷键（← → 翻页，空格翻面，K 标记掌握）
- **掌握度追踪**：每个考点卡片右下角可标记 ✓，闪卡可标记「我记住了」，进度以进度条呈现，全部完成会触发彩带特效
- **即时自测**：每科 12 道单选题，点选即判分并展开解析，实时显示得分
- **全页检索**：输入关键词即时过滤本页考点、结论、单词与卡片
- **明暗主题**：右上角一键切换，偏好保存在本机
- **滚动入场动画、极光背景、卡片 3D 倾斜**：纯 CSS/JS 实现，无外部依赖

所有学习进度与主题偏好均保存在浏览器 localStorage，不联网、不上传。

## 目录结构

    yuekao-review/
    ├── index.html                 首页（学科导航）
    ├── subjects/                  六个学科页面
    │   ├── chinese.html  math.html  english.html
    │   └── physics.html  chemistry.html  biology.html
    ├── assets/
    │   ├── css/style.css          设计系统（含闪卡特效）
    │   └── js/
    │       ├── app.js             渲染与交互引擎
    │       └── data/              六科内容数据 + 首页索引
    └── tools/                     构建与本地预览脚本

## 本地预览

    node tools/serve.cjs 8123
    # 打开 http://127.0.0.1:8123

更新内容后重新生成首页索引：

    node tools/build-index.cjs

## 部署

仓库为纯静态站点，无构建步骤。将 main 分支的根目录设为 GitHub Pages 源即可。

> 说明：物理范围按「人教版必修第三册第十一章 = 电路及其应用」理解整理；生物按「选择性必修1 第 3 章第 1 节 = 激素与内分泌系统」理解整理。若你的教材版本或进度不同，直接在 assets/js/data/ 对应文件中调整内容即可，页面会自动渲染。
