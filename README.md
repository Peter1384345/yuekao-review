# 高二上 · 第一次月考 六科复习站

一个纯静态、可交互的分科复习网站。**每科一个独立页面**，并把 GitHub 上另外两个项目的内容**合并**了进来。

线上地址：<https://peter1384345.github.io/yuekao-review/>

## 页面

- **`index.html`** — 学科导航 + 两个工具入口
- **`subjects/*.html`** — 六科独立页面：考点清单、二级结论、速查表、3D 闪卡、即时自测、掌握度追踪、全页检索
- **`hub.html`** — 全科知识库：按「学段 → 模块 → 重点/难点/考点」浏览，点击展开讲解 / 例题 / 易错提醒，三级掌握度、检索、随机复习、电子课本目录
- **`sprint.html`** — 月考冲刺台：倒计时、按剩余天数自动分阶段的复习计划、各科时间占比、打卡清单、考场策略、108 道考点训练场、六科知识导图

## 交互功能

- **3D 翻转闪卡**：点击翻面，支持随机抽卡、打乱牌序、按标签筛选、「只看未掌握」、键盘快捷键（← → 翻页，空格翻面，K 标记掌握）
- **三级掌握度**：知识库圆点循环「未掌握 → 学习中 → 已掌握」，考点卡片可标记 ✓，闪卡可标记「我记住了」
- **即时自测 / 训练场**：点选立刻判分并展开解析，训练场每轮随机抽 5 题并记录本科最高分
- **全页检索**、**明暗主题**、**滚动入场动画、极光背景、3D 倾斜、彩带特效**

所有学习进度、主题偏好、倒计时与打卡状态均保存在浏览器 localStorage，不联网、不上传。

    yuekao-review/
    ├── index.html                 首页（学科导航 + 工具入口）
    ├── hub.html                   全科知识库

    │       ├── hub.js             知识库逻辑

    │       └── data/
    │           ├── <学科>.js       六科考点 / 闪卡 / 自测
    │           ├── index.js        首页索引

        └── merge-hub.cjs          从源仓库重新转换知识库数据

## 本地预览

    node tools/serve.cjs 8123
    # 打开 http://127.0.0.1:8123

更新六科内容后重建首页索引：

    node tools/build-index.cjs

重新从源仓库抽取内容（需先把源仓库克隆到本地并调整脚本里的路径）：

    node tools/merge-gao2.cjs
    node tools/merge-hub.cjs

> 说明：物理范围按「人教版必修第三册第十一章 = 电路及其应用」理解整理；生物按「选择性必修1 第 3 章第 1 节 = 激素与内分泌系统」理解整理。若你的教材版本或进度不同，直接改 assets/js/data/ 下对应文件即可。
