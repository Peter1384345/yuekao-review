# 高二上 · 第一次月考复习站

一个**融合型**的动态复习站：六科分科页面 + 知识库 + 备考驾驶舱长在同一套信息结构与动效体系里，而不是几个页面拼在一起。

线上地址：<https://peter1384345.github.io/yuekao-review/>

## 融合方式（不是并列，是长在一起）

来源仓库均**未被改动**，内容按下表被拆解重组进本站的信息结构：

| 来源 | 原本形态 | 融合后的位置 |
| --- | --- | --- |
| `high-school-knowledge-hub` | 独立的单文件知识库站点 | 2408 个知识点按学科拆解，成为每科页面的**「本科知识库」区块**（折叠按需加载）；六科知识导图下沉到对应学科页；跨科检索与电子课本保留为 `hub.html` |
| `gao2-monthly-exam-review` | 独立的单页冲刺站 | 倒计时、复习计划、时间占比、打卡清单、考场策略合并为首页的**「备考驾驶舱」**；题库与本站自测合并为统一**训练场**（首页六科切换 + 每科专属）；速查内容并入分科页板块与闪卡 |

## 页面结构

- **`index.html`** — 动态首页：备考驾驶舱（倒计时环 / 环形时间占比 / 复习计划 / 打卡）+ 考场策略 + 全科训练场 + 六科入口 + 融合理念说明
- **`subjects/*.html`** — 六科深度融合页，统一动线：考点清单 → 速查 / 二级结论 → **本科知识库** → 3D 闪卡 → 即时自测 → **本科训练场**
- **`hub.html`** — 知识点 / 电子课本 / 知识导图 三视图，跨科检索与随机复习

## 动态风格

整套视觉从「极光 + 玻璃」升级为**流动光场**，并配有完整动效引擎（`assets/js/motion.js`，零外部依赖）：

- **流动光场背景**：四层色团缓慢呼吸 + Canvas 粒子连线网络，主色随学科主题实时变化
- **页面转场**：支持 View Transitions 的浏览器走原生跨文档转场，其余浏览器用径向揭开遮罩兜底
- **滚动叙事**：顶部渐变进度条、分区差异化的入场（上浮 / 左入 / 缩放 / 模糊散焦）、错峰延迟
- **数字滚动**：统计数字、倒计时从天而降式递增
- **卡片聚光与磁吸**：光斑跟随鼠标（`--mx/--my`），卡片浮起 + 旋转锥形渐变描边
- **涟漪反馈**：按钮、选项、标签点击处扩散涟漪
- **光标光晕**：跟随光斑，延迟跟随
- **环形图表**：倒计时进度环与时间占比环形图均为动画 SVG
- 全站遵循 `prefers-reduced-motion`，关闭动效时自动降级为静态排版

## 交互功能

- **3D 翻转闪卡**：点击翻面、随机抽卡、打乱牌序、标签筛选、「只看未掌握」、键盘 ← → / 空格 / K
- **三级掌握度**：知识库圆点「未掌握 → 学习中 → 已掌握」，与 `hub.html` 进度互通；考点卡片可标记 ✓
- **即时自测 / 训练场**：点选即判分并展开解析，训练场每轮随机抽 5 题、记录本科最高分
- **全页检索**、**明暗主题**（主色随主题与学科联动）、**彩带特效**

所有进度、主题、倒计时与打卡状态都保存在本机 localStorage，不联网、不上传。

    yuekao-review/
    ├── index.html                 动态首页（备考驾驶舱 + 六科入口）
    ├── hub.html                   知识点 / 电子课本 / 知识导图
    ├── subjects/                  六个学科融合页
    ├── assets/
    │   ├── css/style.css          动态设计系统
    │   └── js/
    │       ├── motion.js          动效引擎（光场 / 转场 / 入场 / 涟漪）
    │       ├── app.js             页面渲染与交互引擎
    │       ├── dashboard.js       备考驾驶舱 + 训练场（首页与分科页复用）
    │       ├── kb.js              分科页「本科知识库」融合层
    │       ├── hub.js             知识库三视图
    │       └── data/              六科数据 / 冲刺站迁移数据 / 知识库数据（懒加载）
    └── tools/                     本地预览、索引重建、来源仓库内容抽取脚本

## 本地预览

    node tools/serve.cjs 8123
    # 打开 http://127.0.0.1:8123

六科内容更新后重建首页索引：

    node tools/build-index.cjs

从来源仓库重新抽取（需先把源仓库克隆到本地并调整脚本内的路径）：

    node tools/merge-gao2.cjs
    node tools/merge-hub.cjs

> 说明：物理范围按「人教版必修第三册第十一章 = 电路及其应用」理解整理；生物按「选择性必修1 第 3 章第 1 节 = 激素与内分泌系统」理解整理。若教材版本或进度不同，直接改 assets/js/data/ 下对应文件即可。
